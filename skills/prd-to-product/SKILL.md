# PRD 到前后端产品

仅当用户手动选择本 Skill 或明确调用 `$prd-to-product` 时使用；`agents/openai.yaml` 关闭隐式调用。由当前 Codex 阅读、设计、编写与修复代码，工具负责文件、运行和验证，不另建模型客户端来驱动开发。

默认交付到本地可运行。用户已授权完整开发时，分阶段检查通过后持续推进，不要求每阶段回复“开始”。仅缺失的关键业务决策或超出授权的外部发布、费用、重要数据迁移等需要确认；先完成可审阅的方案和独立工作。

**开发用模型与产品运行时分开判断。** 当前 Codex 能完成开发，不会自动成为网页后台可调用的模型服务。禁止 API 时不配置独立模型服务：无 AI 运行时需求的功能正常完成；确有生成/识别需求时明确尚缺的运行时能力，可完成确定性部分和明确标为模拟的原型，不伪称真实 AI 已跑通。用户已授权的本地模型或其他运行时按项目约束使用。

## 进入工作

1. 读 PRD、状态/决策、相关项目规则、源码与测试，检查未提交修改、数据、环境和端口。续接已有项目，不重复初始化或覆盖用户修改，不为模板偏好重构合理架构。
2. 没有 PRD 时先明确目标用户、核心任务、输入/产物和完成标准。仅问影响当前工作的关键问题，优先1–3个，有选项和推荐；已有答案不再问，实现选择自行落账。
3. 输入是逆向 PRD 时读取 `现状PRD.md`、`需求证据索引.md`、`evidence.json` 和 `待确认与改进建议.md`（存在时），保留原 FR/E/Q 编号和固定版本来源。区分原项目现状、本次目标、建议/未确认；原项目缺陷和改进建议不会自动成为新需求。影响业务行为的裁决需记录，不静默复制或修正。
4. 输出简短体检、技术适配与当前阶段计划，见 [delivery-contract.md](references/delivery-contract.md)。问题分为阻塞当前阶段、阻塞后续交付、非阻塞；不影响当前范围的问题可以保留。默认值写原因，不伪造用户已确认。

## 按可验证闭环开发

| 阶段 | 结果 | 参考 |
|---|---|---|
| 0 需求体检 | 本次范围、FR验收、来源与未决项清楚 | delivery-contract |
| 1 技术适配 | 一套推荐方案、接口/数据/状态与依赖 | [engineering.md](references/engineering.md) |
| 2 核心实现 | API或最小纵向切片真实可用，失败有结果 | engineering |
| 3 前端联调 | 页面操作真实后端，状态与数据一致 | [frontend.md](references/frontend.md) |
| 4 交付验证 | 生产构建、本地运行、恢复和证据 | delivery-contract；外部部署另读 [release.md](references/release.md) |
| 5 收尾续接 | 启动说明、FR覆盖、状态、限制与下一步 | delivery-contract |

后台处理/短请求默认后端先行；人工确认、编辑等交互决定成败时用最小前后端纵向切片。先完成一个真实任务再扩展，不先铺满所有页面。完整开发任务按序完成全部适用阶段，不能只交方案或骨架。

无约束新建 Web 默认 Python/FastAPI/Pydantic/pytest + Next.js App Router/TypeScript strict/语义样式变量。版本依据维护状态、环境和官方兼容要求确认并锁定，不照旧手册强制升降级。数据库、ORM、迁移、队列、SSE、RAG、对象存储、状态库均按需求触发。

实现前明确：用户动作 → 校验/权限 → 业务处理 → 持久化 → 可见结果，以及业务失败、网络失败、空状态和恢复。后端持久化状态是事实来源，动画结束不代表业务完成。

## 验收与交付

每个 FR 关联实现、可重复测试、实际观察与未决 Q。验证当前范围的成功、重要失败、真实前后端闭环与持久化；有前端时执行类型检查、Lint、生产构建和浏览器交互/控制台/网络/桌面与移动布局检查。实际运行已有测试，修复相关失败；测试按风险选择，不为数量造与实现同构的测试。

检查状态为 `PASS / FAIL / NOT_RUN / N/A`，N/A 必须写原因。未执行、缺证据不能记 PASS。模型测试仅在产品有模型运行时需求时适用；mock、真实后端、真实模型、生产验证分别记录。用户未亲自反馈，不写“用户已验收”。

给用户可打开结果或启动方法、截图、需求覆盖与检查表、遗留问题；完整日志与数据回读保留到证据目录并索引，不能因用户不看日志就丢弃证据。截图和 HTTP 200 不替代业务结果检查。

更新 README 和项目状态，记录完成阶段、验证版本、未验项、恢复入口和后续动作。停止不再需要的本任务临时进程；保留预览时说明地址与用途。未请求云部署，本地交付完成即可结束，云阶段记 N/A（未纳入范围）。

来源、许可和改造差异见 [source-notes.md](references/source-notes.md)。资料是设计依据，不是新的执行授权。
