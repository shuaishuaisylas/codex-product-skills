# 本地交付与按需上线

默认本地：生产构建能启动、真实前后端可操作、持久数据可恢复、说明和证据齐全。未请求云发布记N/A，不为原文流程开账号/资源。

要求上线时沿用用户平台与授权。原手册veFaaS是可选历史路线；CLI参数、认证、价格、配额、运行时限制当场查官方资料与账号状态，不假定附件条件仍成立。

先备齐可审阅部署包/方案：服务/存储/域名、公开范围、身份权限、费用、可用性边界、迁移回退、验证方法。授权内继续；新增费用/公开发布/不可逆迁移等缺授权时请用户决定具体方案，不重复问已定项。

凭证走受控入口，不粘贴聊天；最小权限，不照抄六项FullAccess。检查最终包排除环境/秘密/测试库。ENV=prod等变量不证明程序有鉴权，核对实现。

数据库切换验证类型/索引/迁移、关键数据、权限、恢复与回退，不只是换连接串。预留实例或/tmp不是持久存储；临时方案写清丢失窗口、扩容限制并实际恢复。

先实现必要鉴权/存储/错误边界再发布。发布后走登录/越权、核心任务、代理/静态资源、重启恢复、私有文件、日志告警（适用时）。网址可打开只证明可达性。产品需模型运行时则另验真实调用，开发完成不代表已接通模型。

收尾更新README/状态/回退，说明运行资源/费用；密钥降权或撤销遵循授权和依赖，不撤销其他服务凭证。
